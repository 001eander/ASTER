# 因子评估体系 v2：样本分层、门控与评分

Status: accepted（2026-10-15，issue #134，决策地图 #128）

因子评估从「全样本单段、score = rank_ic × 相关折扣」重做为「三段分层、双段六道门控、废除单一 score」，同时删除现有 26 个 pool 因子。直接输入是诊断报告 `docs/research/eval-diagnosis.md`（issue #133）：全样本评估掩盖年度失稳、score 被相关折扣主导且与门控脱节、门控阈值中途变更无元数据可溯、查重参考池随库增长漂移。

## 决定

**样本分层**：开发段 2021-09-29 ~ 2024-12-31（挖掘 agent 可见可优化，2021 只当预热带）；选择段 2025 全年（门控判定段，agent 不可见）；样本外段 2026-01-01 ~ 2026-09-24（封存，不进任何门控，只供事后复核）。样本外每年前移一次，上年并入选择段；旧评估产物封存不重算，靠 thresholds 与 scorer_version 元数据复现。

**评估样本池**：只沪深，剔除北交所；ST 不处理；停牌与涨跌停按冻结持仓处理（订单递延、仓位维持）。

**门控**（六道线，开发段与选择段各自过线，全部费后）：

| 线 | 阈值 | 口径 |
|---|---|---|
| Rank IC | > 0.02 | 日 Rank IC 均值 |
| Rank ICIR | > 0.7 | 日 IC mean/std |
| Sharpe | > 1.58 | 十分组多空组合费后日收益年化 |
| turnover | < 0.7 | 十分组多头组日成员变化率均值 |
| max_corr | < 0.7 | 相对参考池快照，相关在选择段冻结窗口上算 |
| Barra PnL Corr | < 0.3 | 候选因子与六风格各十分组多空 PnL 日收益相关绝对值最大 |

mono 门删除。多头超额 Sharpe、t 统计、正 IC 日占比、逐年 IC/ICIR 只陈列不卡线。回测为评估内嵌的简化向量化回测：十分组等权，h=1（T+1 open → T+2 open）卡线，h=5 全套陈列，费率用 `quant/backtest/fee.py`。

**评分**：废除单一 score。评估产物 = gate_passed + gate_failures + 多维指标陈列（score.json schema v2：scorer_version / segments / thresholds / reference_pool_version / 分段与逐年 metrics）。候选因子的排序键交课题层，不在评估器内定义。

**查重与存量**：参考池冻结为带版本号的快照。现有 26 个 pool 因子随 v2 上线全部删除，库从零增长。

## Considered Options

- ICIR 阈值：校准数据显示日 ICIR >= 0.7 在 59 个既有因子上通过数为 0（分段最大 0.582）。讨论过放松到 0.3（双段 23/59）或 0.35（12/59），最终维持 0.7，明确接受「库从零增长、挖掘 loop 短期无产出」的代价，理由是因子质量标准严格优先于库存量。
- score 公式：讨论过保留与门控同源的单一分数（过线才计分），最终整个废除。诊断显示任何单一标量都会把多维权衡压扁成 agent 博弈对象（被优化的 score 与后段 IC 秩相关仅 +0.418，裸 rank_ic 为 +0.955）。
- 样本外使用纪律：讨论过永不见光与定期揭盲复核，最终选滚动前移，接受多重检验污染随时间累积的风险。
- 存量处置：讨论过既往不咎（v1 因子保留、指标重算陈列）与先整库 prune 再保留，最终全删。

## Consequences

- 库清空后参考池从空开始，头几个入库因子的 max_corr 门没有参照物，Barra PnL 相似度门是早期唯一的换皮防线。
- 旧 score.json（v1，含 score 字段）只读兼容，promote.py 拒绝用 v1 产物新入库。`src/experience-bank.ts` 的 Score 类型与比较逻辑随之改造。
- 第一轮讨论的「先跑整库 prune 清 8 对越线因子」被全删取代，不再执行。
- 样本外段目前只有约 180 天，第一次前移（2027 年初）之前整库复核结论的统计功效有限。
- 实现拆分：Barra PnL 相似度门单独一票（复用 `quant/portfolio/style.py` 六风格，风格因子本身不动）；因子回测重做与 v2 评估器同票；池级评估与课题层排序键归后续票。
